# Blind Tennis 

音と直感を頼りにプレイする、ブラインドテニスのGo言語実装版です。

## 特徴
- **音響重視**: ボールの位置や高さを音の変化で感じ取ることができます。
- **音声読み上げ**: スコアや試合状況を音声でアナウンスします（Windows版はSAPIを使用）。
- **3D物理シミュレーション**: 重力、空気抵抗、バウンドを考慮した本格的なボール挙動。

## 動作環境
- Go 1.20以上推奨
- Windows (推奨: 音声読み上げ機能のため)
- その他のOS (音声はコンソール出力のフォールバックとなります)

## 開発者向け情報

### 依存関係
このプロジェクトは以下のライブラリを使用しています。
- [Ebitengine (v2)](https://ebitengine.org/): ゲームエンジン
- [go-ole](https://github.com/go-ole/go-ole): Windows SAPI操作用

### ビルド方法
以下のコマンドで実行ファイルをビルドできます。
```bash
go build -o tennis-go.exe main.go
```

## 実行
ビルド済みの `tennis-go.exe` を実行するか、`go run main.go` で直接起動してください。

## 遊び方

### 1. ゲーム開始
アプリケーションを起動すると、自動的に「試合開始。」とアナウンスされ、ゲームがスタートします。

### 2. サーブのルール
サーブ権がある場合（プレイヤー）：
1. **`1`**, **`2`**, **`3`** キーを押してサーブの種類を選択します。
   - **`1`**: スライスサーブ（速く低い軌道）
   - **`2`**: ドライブサーブ（標準的な軌道）
   - **`3`**: アンダーサーブ（高く遅い軌道）
   選択すると、そのサーブ名が音声で読み上げられます。
2. **`Space`** キーを押して「いきます」と合図します。
3. コンピューターが「はい」と返したら、もう一度 **`Space`** キーを押してサーブを打ちます。

コンピューターのサーブの場合：
1. コンピューターが「いきます」と言ったら（コンピューターはランダムにサーブを使い分けます）、**`Space`** キーを押して「はい」と返します。
2. コンピューターがサーブを打ちます。

### 3. 移動とショット
- **移動**: **`矢印キー (↑↓←→)`** を使用して、自分のコート内を移動します。
- **ショット**: ボールが近くに来たタイミングで **`Space`** キーを押してラケットを振ります。
- **バウンド**: ブラインドテニスのルールに基づき、3バウンド以内に打ち返す必要があります。

### 4. スコア
テニスの標準的なスコアリング（0, 15, 30, 40, Game）で進行します。
ポイントが決まるたびに、現在のスコアが「サーバー 〇〇、レシーバー 〇〇」と音声でアナウンスされます。また、ゲームが決まった際には「ゲーム。ゲームカウント 〇対〇」とアナウンスされます。

## 操作一覧
| キー | 動作 |
| :--- | :--- |
| **`1`**, **`2`**, **`3`** | サーブの種類を選択（サーブ時のみ） |
| **`矢印キー`** | プレイヤーの移動 |
| **`Space`** | ラケットを振る / サーブの合図・返答 |

## 技術スタック
- **Game Engine**: [Ebitengine (v2)](https://ebitengine.org/)
- **Audio Logic**: 3Dパンニング・ピッチ制御対応自作エンジン
- **Voice Synthesis**: Windows SAPI (via `go-ole`)
