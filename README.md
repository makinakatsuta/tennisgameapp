# ブラインドテニスゲーム

音を頼りにプレイする、シンプルなブラインドテニスゲームです。
プレイヤーを矢印キーで動かし、ボールが近づいたらSpaceキーで打ち返します。

## すぐに遊ぶ

1. `tennis-go.exe` を起動します。
2. 矢印キーでプレイヤーを動かします。
3. ボールが近づいたタイミングで `Space` を押します。

## 操作方法

| キー | 操作 |
| --- | --- |
| `↑` `↓` `←` `→` | プレイヤーを移動 |
| `Space` | ラケットを振る／サーブの合図や返答 |
| `1` `2` `3` | サーブの種類を選ぶ（プレイヤーのサーブ時） |

## ゲームの特徴

- ボールの位置や距離に応じて音が変化します。
- プレイヤーの移動に合わせて、ボール音・バウンド音・ラケット音の方向と距離感が変わります。
- スコアや試合状況を音声で案内します。
- プレイヤーとCPUが対戦します。

## 動作環境

- Windows推奨（音声案内にWindows SAPIを使用）
- その他のOSでは音声案内がコンソール出力になります。

## 実行

ビルド済みの `tennis-go.exe` を起動してください。

開発環境で実行する場合は、Go 1.26.3以降を使用してください。

## ブラウザで遊ぶ

`web` フォルダにある `index.html` を、ファイルを直接開かずHTTPサーバー経由で表示してください。

WASMを作り直す場合は、プロジェクトのフォルダで次を実行します。

```powershell
.\build-wasm.ps1
```

その後、プロジェクトのフォルダでHTTPサーバーを起動し、`http://localhost:8000/web/` を開きます。

```powershell
python -m http.server 8000
```
